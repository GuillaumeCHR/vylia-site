# VYLIA — site

Site statique de [VYLIA : privacy score & manager](https://github.com/GuillaumeCHR/VYLIA) (GitHub Pages) : accueil avec
la carte d'identité de l'app, politique de confidentialité, conditions d'utilisation, en anglais et en français. Aucun
script, aucune ressource externe, aucun cookie. Captures copiées de `docs/screenshots` du dépôt de l'app ; police du nom
(Unbounded) réduite aux lettres utilisées.
